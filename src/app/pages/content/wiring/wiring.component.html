Keycloak for Angular — Packages

keycloak-js (v25.0.4) is the official, framework-agnostic JavaScript adapter that talks directly to the Keycloak server: builds login URLs, handles callbacks (?code&state), manages tokens, and exposes helpers like updateToken(), loadUserProfile(), etc.

keycloak-angular (v16.0.1) is a thin Angular wrapper around keycloak-js. It adds Angular-friendly pieces: DI services, route guards, and an HTTP interceptor for attaching bearer tokens to API calls.

How They Work Together

  1. Init — Your app creates a Keycloak instance (via keycloak-js) and calls kc.init() (usually with PKCE).
  2. Login — User is redirected to Keycloak; after login, Keycloak redirects back with ?code&state.
  3. Token Exchange — The adapter completes the code→tokens exchange and stores access/refresh/ID tokens.
  4. Angular Glue — keycloak-angular exposes an Angular service/guard and (optionally) an interceptor to add Authorization: Bearer <token> to outgoing HTTP calls.
  5. Refresh — keycloak-js refreshes tokens before expiry (updateToken()), keeping the session alive.

Version Notes & Compatibility

  • Server: Works with modern Keycloak servers (e.g., Keycloak 26).
  • PKCE: Use pkceMethod: 'S256' in kc.init() for SPAs.
  • Callback Mode: Prefer responseMode: 'query' to avoid hash fragments.
  • CORS: Configure Valid Redirect URIs and Web Origins on the Keycloak client (e.g., http://localhost:4200/* and http://localhost:4200).

If you mix major versions, pin them and test login/refresh flows carefully.

Minimal Wiring (Sample)

// keycloak.service.ts (conceptual)
import Keycloak from 'keycloak-js';

const kc = new Keycloak({
  url: 'http://localhost:8080',
  realm: 'pkce_realm',
  clientId: 'pkce_client'
});

await kc.init({
  pkceMethod: 'S256',
  checkLoginIframe: false,
  responseMode: 'query' // avoid #fragment
});

// Optional: attach token to HTTP calls via keycloak-angular interceptor

In Angular, inject your service or KeycloakService (from keycloak-angular) in components/guards.

Tips & Pitfalls

  • Set Valid Redirect URIs and Web Origins in Keycloak to prevent CORS and callback errors.
  • Use Authorization Code + PKCE (avoid implicit flow for SPAs).
  • Keep access tokens short-lived; rely on refresh tokens for continuity.
  • Prefer /protocol/openid-connect/userinfo over legacy /account endpoints for user claims.
