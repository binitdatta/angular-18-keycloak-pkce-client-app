Admin Logout — Component & Guard

This page shows a simple logout success component and a LogoutRouteGuard that prevents navigating to the logout screen when the user is still authenticated (redirects home instead).

Admin Logout Component (Example)

import { Component } from "@angular/core";

@Component({
  selector: 'app-admin-logout',
  template: `
    <div class="content">
      <h3>Logout Successful</h3>
      <p>You have been signed out.</p>
    </div>
  `
})
export class AdminLogoutComponent { }

LogoutRouteGuard (Example)

If the user is already logged out, the route is allowed. If still logged in, it redirects to Home. 

import { inject } from "@angular/core";
import { CanActivateFn, Router } from "@angular/router";
import { AppRoutes } from "../app-routing.module";
import { AuthenticationService } from "../services/authentication.service";

export const LogoutRouteGuard: CanActivateFn = () => {
  const authenticationService = inject(AuthenticationService);
  const router = inject(Router);

  if (!authenticationService.isLoggedIn()) {
    return true; // already logged out, allow navigation
  } else {
    return router.createUrlTree([AppRoutes.Home]); // still logged in, redirect to Home
  }
};

Wiring in Routes

const routes: Routes = [
  // Only show logout page when NOT authenticated
  { path: 'logout', canActivate: [LogoutRouteGuard], component: AdminLogoutComponent },
  // ...
];

Remember to declare or import the component, and export the guard from a file the router can import.
