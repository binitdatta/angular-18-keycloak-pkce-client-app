Why Cybersecurity Matters Everywhere

Every industry—banking & finance, manufacturing, healthcare, retail, and supply chain—handles sensitive data and high-value transactions. Modern threats target identity first, so strong authentication and authorization are essential.

OAuth 2.0 secures API access with short-lived access tokens, while OpenID Connect (OIDC) adds a reliable identity layer via ID tokens and the UserInfo endpoint. Together, they enable SSO, least-privilege access, and standards-based integrations across clouds and platforms—exactly what global enterprises need.

Tutorials — OAuth2 + PKCE Demo

This page demonstrates the Authorization Code + PKCE flow with Keycloak 26 from an Angular SPA. Sign in, list data, and see how tokens enable authenticated requests.

Keycloak Setup (Checklist)
  1. Create realm (e.g. pkce_realm).
  2. Create client pkce_client:
    • Public client, Standard flow ON.
    • PKCE method S256 enabled.
    • Valid Redirect URIs: http://localhost:4200/*
    • Web Origins: http://localhost:4200 (or * for dev)
    • Default scopes: openid profile email
  3. Create a test user with password.
Tip: Check discovery at /.well-known/openid-configuration.
