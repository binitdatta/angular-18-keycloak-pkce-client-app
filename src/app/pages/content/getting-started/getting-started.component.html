Start a New Angular Project (Non-Standalone)

Create a classic NgModule-based project by passing --standalone=false. 

# Install Angular CLI (if needed)
npm i -g @angular/cli

# Create a new project using NgModules
ng new my-app --standalone=false

# Run the dev server
cd my-app
ng serve -o

This scaffolds AppModule, classic main.ts bootstrapping, and a conventional src/ tree.

polyfills.ts — Browser Shims

/******************************************************************
 * Add browser polyfills if needed. Modern Angular often lists them
 * directly in angular.json ("polyfills": ["zone.js"]).
 ******************************************************************/
import 'zone.js'; // Required by Angular

main.ts — Bootstrapping with AppModule

import { platformBrowserDynamic } from '@angular/platform-browser-dynamic';
            import { AppModule } from './app/app.module';

            platformBrowserDynamic()
            .bootstrapModule(AppModule)
            .catch(err => console.error(err));

Build & Serve

  1. TypeScript compiled to JS with Angular compiler.
  2. Bundled & optimized by the Angular CLI builder.
  3. Assets copied from src/assets; styles injected globally.
  4. File replacements can swap environments for production.
  5. Output in dist/my-app, ready to deploy.
# Dev (with HMR-like live reload)
ng serve

# Production (optimized)
ng build --configuration production
