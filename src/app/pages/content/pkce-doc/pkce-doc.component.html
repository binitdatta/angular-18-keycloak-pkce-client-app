PKCE (Proof Key for Code Exchange)

PKCE protects the Authorization Code flow for public clients (SPAs, mobile) by binding the authorization code to a one-time secret only the client knows.

How it works

  1. Generate a high-entropy code_verifier on the client.
  2. Compute code_challenge = BASE64URL(SHA256(code_verifier)).
  3. Send the code_challenge with the authorization request.
  4. Exchange the code at the token endpoint by sending the original code_verifier.
  5. The server recomputes and compares; if it matches, tokens are issued.

In keycloak-js

Enable with pkceMethod: 'S256' in keycloak.init({ pkceMethod: 'S256' }).

Tips

  • Use HTTPS.
  • Keep access tokens short-lived; use refresh tokens carefully.
  • Don’t send refresh tokens to APIs.
