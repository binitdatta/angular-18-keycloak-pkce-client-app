1) environment.ts — runtime config

In development (ng serve) Angular uses environment.ts. Production builds can replace it with environment.prod.ts via file replacements. 

// src/environments/environment.ts
export const environment = {
  production: false,
  keycloak: {
    enable: true,
    authority: 'http://localhost:8080',
    redirectUri: 'http://localhost:4200',
    postLogoutRedirectUri: 'http://localhost:4200/logout',
    realm: 'pkce_realm',
    clientId: 'pkce_client',
    apiBase: 'http://localhost:9045/api'
  }
};

2) AppModule — bootstrap & Keycloak init

Root module imports HttpClientModule and KeycloakAngularModule, then initializes Keycloak via APP_INITIALIZER so initial auth state is ready before the UI renders. 

// src/app/app.module.ts (excerpt)
imports: [
  BrowserModule,
  HttpClientModule,
  KeycloakAngularModule,
  AppRoutingModule,
  FormsModule
],
providers: [
  {
    provide: APP_INITIALIZER,
    useFactory: initializeKeycloak,
    multi: true,
    deps: [KeycloakService]
  }
]

With onLoad: 'check-sso' the app adopts an existing Keycloak session if present.

3) Routing — landing & protected routes

AppRoutingModule maps URLs; guards protect sensitive routes. 

// src/app/app-routing.module.ts (snippet)
const routes: Routes = [
  { path: '', redirectTo: 'tutorials', pathMatch: 'full' },
  { path: 'tutorials', component: TutorialsListComponent },
  { path: 'add', canActivate: [AuthGuard], component: AddTutorialComponent },
  { path: 'docs/customers', component: CustomersComponent },
  { path: '**', redirectTo: '404' }
];

4) AuthenticationService — facade over Keycloak

Components call this service to login, logout, check auth state, and read the username, without touching Keycloak APIs directly. 

// src/app/services/authentication.service.ts (excerpt)
redirectToLoginPage(): Promise<void> { return this.keycloakService.login(); }
get userName(): string { try { return this.keycloakService.getUsername() ?? ''; } catch { return ''; } }
isLoggedIn(): boolean { return this.keycloakService.isLoggedIn(); }
logout(): void { this.keycloakService.logout(environment.keycloak.postLogoutRedirectUri); }

5) Navbar — shows Login or user + Logout

The navbar queries the service. When logged in, it displays the username and a Logout button. 


<ul class="navbar-nav ms-auto mb-2 mb-lg-0">
  <ng-container *ngIf="isLoggedIn(); else loginLink">
    <li class="nav-item"><span class="nav-link text-light">{{ username() }}</span></li>
    <li class="nav-item"><button class="btn btn-outline-light" (click)="logout()">Logout</button></li>
  </ng-container>
  <ng-template #loginLink>
    <li class="nav-item"><button class="btn btn-outline-light" (click)="login()">Login</button></li>
  </ng-template>
</ul>

6) Sequence: startup → login → return

  1. ng serve loads the dev environment.ts.
  2. Bootstrap: APP_INITIALIZER runs and initializes Keycloak JS.
  3. First render: Router shows landing + navbar; service reports auth state.
  4. Login: Clicking Login calls redirectToLoginPage() and navigates to Keycloak.
  5. Authenticate on Keycloak; it redirects to redirectUri with an auth code.
  6. Exchange: Keycloak JS trades the code for tokens; session is ready.
  7. UI updates: Navbar now shows the username; guards permit protected pages.
  8. APIs: Services call Spring Boot at environment.keycloak.apiBase.
Browser           AppModule/Router             Keycloak JS            Keycloak
   |                      |                         |                     |
   | -- ng serve -------->|                         |                     |
   |                      |  APP_INITIALIZER init   |-- discovery ------->|
   |                      |                         |<-- config ----------|
   |                      |  render navbar/landing  |                     |
   | click Login          |-- AuthService.login() --|-- /authorize ----->|
   |                      |                         |<-- redirect (code)--|
   |                      |                         |-- /token ---------->|
   |                      |                         |<-- tokens ----------|
   |                      |  navbar shows username  |                     |
   |  calls /api/... ---->|                         |                     |

7) Customers service — API base

Services read their base URL from environment.keycloak.apiBase. 

private base = environment.keycloak.apiBase;  // http://localhost:9045/api
getCustomers(): Promise<Customer[]> {
  return firstValueFrom(this.http.get<Customer[]>(`${this.base}/downstream`));
}
